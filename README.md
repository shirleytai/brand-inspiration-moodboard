## 使用與分享
開啟 index.html，或以靜態伺服器提供完整資料夾。建議使用正式HTTPS網址。跨主分類與子分類勾選後，點分享我的選擇，再複製連結或使用系統分享，傳給設計師。分享視窗會顯示明確回饋；剪貼簿被禁止時可手動複製。結果只存在此裝置，不會自動回傳。含 selected 參數的連結可還原選圖，取代目前裝置選擇；舊的 #01–#33 分享連結仍適用。

## 修改與部署
js/data.js 管理 id、title、category（brand/web）、subcategory、image、description、tags、source、width、height。js/app.js 管理分類定義與互動；css/style.css 管理排版。source 保留來源檔名，原始Pinterest網址未隨本機圖片提供，因此不虛構來源連結。

所有圖片皆來自使用者提供的本機素材，非AI生成；品牌名稱與說明為視覺辨識，仍可校正。原始完整Pinterest順序無法考證，原33圖編號沿用先前重建版。
