# 品牌設計靈感白板

純靜態網站，使用 33 張使用者本機原圖，無外部圖庫、登入、後端或追蹤。

## 本機開啟
直接開啟 index.html。推薦使用靜態伺服器（例如 python3 -m http.server 8000）再瀏覽 http://localhost:8000，讓儲存與分享功能更穩定。瀏覽器若禁止儲存，頁面仍可當次勾選。雙擊本機 HTML 時請複製清單回傳；file:// 連結不能讓其他人取得你電腦上的檔案。

## GitHub Pages
將本資料夾內全部檔案上傳至 GitHub repository 根目錄。Settings → Pages → Deploy from a branch，選 main 與 / (root)，等待部署，再使用 GitHub Pages 網址。若放在子目錄，使用對應子目錄網址。所有圖片與程式均使用相對路徑。

## 勾選與回傳
點卡片右上角方框可勾選；點圖片開啟詳情。已選圖片入口可篩選、清除及分享。勾選保存在目前裝置的瀏覽器，不會自動同步給設計師。請使用「分享我的選擇」主動回傳連結。分享網址含 ?selected=2,5,11,23；收到連結時，其結果會取代本機目前選擇。沒有 selected 參數時使用本機儲存紀錄。空 selected 參數代表清空。Web Share API 不支援時會複製網址；剪貼簿不支援時顯示可手動複製的文字。

## 修改內容
js/data.js 的 ITEMS 管理 id、title、category、image、description、source。圖片位於 images/，保留原比例。category 1–3 分別對應文字主角、圖形主角、字圖融合；tags 為彈窗中的風格感受標籤；js/app.js 管理分類介紹。未能清楚辨識的品牌採描述性標題，說明為重建的視覺觀察，並非原作者文字。

## 編號與分類來源限制
